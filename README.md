## ✨ Features

- ⚡ **Blazing Fast Performance:** Powered by Astro's static site generation (SSG) with zero unnecessary client-side JavaScript.
- 🎨 **Modern Dark Aesthetics:** Custom dark-purple and violet palette with subtle ambient glow effects and clean glassmorphic touches.
- 🚀 **Product Studio:** Dedicated showcase for digital platforms and SaaS products (**MenuDrapp**, **Thiscita**, **La Liguita**).
- 🛠️ **Curated Tech Stack:** Dedicated section highlighting proficiency across Frontend, Backend, Databases, and DevOps.
- 💼 **Case Studies & Projects:** Split between independent personal products and production client websites.
- 💬 **Interactive Contact Modal:** Direct communication access via Email, WhatsApp, LinkedIn, and Instagram.
- 🌐 **Multilingual Ready:** Dedicated Spanish and English routes for `/product-studio` and `/links`.
- 🔍 **SEO & Social Share Ready:** Complete Open Graph and Twitter Cards meta configurations.

## 🚀 Getting Started

### Prerequisites

- Node.js `18.17.0` or higher
- npm, pnpm, or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/robertfrontend/portfolio-2024.git
   cd portfolio-2024
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:4321` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build locally:**
   ```bash
   npm run preview
   ```
